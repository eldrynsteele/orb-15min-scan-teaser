# ORB trade pings — memo

## The teaser works on its own

Yes — this free teaser works. Install it in Muse (for best results, use
Muse), ask Muse to run the scan, and it will grade your tickers
ready / waiting / rejected / already played out, using the manual scan in
`SKILL.md`. Nothing is ordered without a preview and your explicit yes.

## What the teaser does not do

The teaser does not send trade pings. It only answers when you ask it for
a read. It does not watch in the background, and it never places a trade.

## Trade pings come with the full skill

Installing pings for trades comes with the full `orb-15min-breakout` skill
purchase. The full skill includes the install memo for setting pings up on
your own Muse agent.

That install memo is not in this teaser repo — it ships with the full skill,
after purchase.
