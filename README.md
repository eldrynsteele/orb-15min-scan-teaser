## The manual scan

1. Mark the 9:30–9:45 ET range on your watchlist
2. Wait for a candle to CLOSE beyond the range (wicks don't count)
3. Confirm with above-average volume and price vs. VWAP
4. Grade: ready / waiting / rejected / already played out
5. Entries use 1:1 risk/reward, preview + explicit yes before anything
